# Spam y teoría de la decisión

| Archivo | Qué es |
|---|---|
| `spam_teoria_decision.ipynb` | El trabajo (ya ejecutado): problema → solución → demostración → conclusión. |
| `spam_utils.py` | Código auxiliar: carga de datos, regresión logística por descenso de gradiente y métricas. |
| `guia_defensa.md` | Guion de 10 minutos, derivación para la pizarra y preguntas probables. |
| `data/spambase.data` | Datos (Spambase, UCI). |

**Ejecutar:** activad `entorno\.venv` y luego `jupyter lab spam_teoria_decision.ipynb` desde esta carpeta (o, en VS Code, kernel «ml-cunef» → *Run All*). Con la semilla fijada, los números salen siempre iguales.

Nota: los números son distintos de los del borrador de la fase 1 porque el modelo es ahora una regresión logística programada con las matemáticas del temario, y se ha quitado Naive Bayes (no está en el temario).
